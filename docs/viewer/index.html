Built on the macropad you already shipped

      

      
Macropad v2.1 runs on an ESP32-S2 with 12 mechanical keys over USB HID, with Macropad Studio as its Electron app. Its schema, serial protocol, non-blocking macro engine, atomic storage, backups, AI shortcuts and context switching are proven. The Touch Keypad keeps all of it and replaces only what the new hardware forces: the HID transport, the input layer, the screen, and the flasher's reset method.

        JSON uploads keep v2.1's parse-before-commit, atomicWrite and 5 s stall timeout. The cap rises from 16 KB to 64 KB for multi-page profiles. Tile uploads are checked by CRC32 before they're renamed into place.
        
      
        
    
        
    
        
      
        
        
        Host actions without a data link
        
        
        A host action makes the keypad send a reserved combo such as Ctrl+Alt+Shift+F13. Studio registers these with Electron's globalShortcut and runs the mapped command: open an app or URL, switch an OBS scene, or run a script. This works over BLE with no custom service, inside the Studio app that already runs in the tray.
        
        
        12 F-keys × 4 modifier sets = 48 host slots. If Studio isn't running, the combo does nothing harmful.
        
      
        
      
        
        
        Security
        
        
          
          
        • Pairing shows a 6-digit passkey and a 60 s countdown ring on the keypad. Just Works is allowed only inside that window.
          • 
          
        • 3 host slots, each with its own static address and bond. Each slot has a forget button.
          • 
          
        • Config lock: wireless (NUS) writes need Unlock on the device. USB writes are trusted, as in v2.1.
          • 
          
        • Macros are data. Uploads are parsed and validated before commit, the last 3 versions are kept as .bak, and the device safe-boots to a default profile.

        Stream Deck's model, a watch's polish, and keys that work without an app
        
      
        
      
        Every Stream Deck is wired and needs its app running. Spotify Car Thing showed how good a simple touch UI with a dial feels. Apple and Samsung watches set the bar for tiles, rings and sheets on a small screen. This keypad combines those ideas and still works as a plain Bluetooth keyboard.
